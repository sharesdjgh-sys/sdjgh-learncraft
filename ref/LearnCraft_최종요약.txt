═══ 문제 정의 ═══
한 줄 소개: 고등학생이 교육과정 단원에 맞는 AI 튜터와 함께 수준별 맞춤 학습을 만들어가는 교육 플랫폼 LearnCraft
해결하려는 문제: 고등학생들이 GPT·Gemini·Claude 등 범용 AI를 사용할 때 교육과정 범위를 벗어난 답변을 받거나, 유·무료 서비스 격차로 학습 형평성이 무너지는 문제. 또한 AI를 어떻게 활용해야 공부에 도움이 되는지 모르는 학생들이 많아 AI가 학습 도구로 제대로 기능하지 못하는 문제.
배경 및 필요성: 현재 고등학생들은 학습 목적으로 AI를 사용하지만 교육과정과 무관한 답변, 유료·무료 서비스 간 품질 격차, 비교육적 사용 등의 문제가 존재함. 학교가 API 비용을 부담하여 모든 학생이 동등하게 고품질 AI를 사용할 수 있도록 하고, 교육과정 단원 기반 프롬프트 엔지니어링으로 학습 최적화된 답변을 제공하는 플랫폼이 필요함. 학교 플랫폼과 SSO 토큰 연동으로 별도 가입 없이 자동 로그인되며, Next.js 풀스택·Neon DB·Vercel 기반으로 구축됨.

기능 개요:
① 학교 플랫폼 SSO 자동 로그인 및 학년·과목·단원 선택(선행학습을 위한 학년 변경 허용) ② 교육과정 단원 기반 시스템 프롬프트로 범위 외 질문 제한 및 소크라테스식 학습 유도 ③ 답변 후 '더 쉽게·더 자세히·답 보여줘·관련 퀴즈' 버튼으로 수준별 맞춤 학습 제공 ④ 단원별 핵심 공식·개념 요약 자료 캐싱 제공 ⑤ 학생이 선택한 답변만 북마크하는 오답 노트 기능 ⑥ 학생별 일일 사용량 제한 및 관리자 사용 현황 대시보드(학생별 사용량·단원별 질문 빈도·API 비용 현황)

═══ 이해관계자 분석 ═══
▸ 고등학생 (주요 사용자, 15~18세 (고1~고3))
  현재 불편함: 현재 Gemini, GPT, Claude 등 일반 AI를 공부에 활용하지만 교육과정과 무관한 답변을 받거나, 유료/무료 버전 차이로 학습 격차가 발생하고 있다. 방대한 AI 답변 중 시험에 필요한 내용이 무엇인지 스스로 걸러내야 하는 부담이 크다.
  SW 사용 목적: 학교 교육과정 단원에 맞춘 AI 튜터를 통해 시험 범위에 집중된 학습을 하고자 한다. 모르는 개념을 쉽게/상세하게 단계별로 선택하며 자신의 수준에 맞게 학습하고, 관련 퀴즈와 오답 노트로 학습 완결성을 높이려 한다.
  SW와의 관계: 학교 플랫폼 SSO 로그인으로 자동 연동되어 LearnCraft에 접속하며, 학교가 구매한 API를 통해 무료/유료 차별 없이 동일한 고품질 AI 서비스를 이용하는 핵심 수혜자이다.

▸ 학교 관리자 (운영자, 학교 행정 담당자 또는 정보 담당 교사)
  현재 불편함: 학교 예산으로 API 비용을 지출하는 만큼 학생별 사용량과 전체 비용 현황을 실시간으로 파악하기 어렵고, 특정 학생의 과도한 사용을 통제할 수단이 없어 예산 관리에 불안함을 느낀다.
  SW 사용 목적: 관리자 대시보드를 통해 학생별 사용량, 과목·단원별 질문 빈도, API 비용 현황을 모니터링하고자 한다. 일일 사용량 제한 설정으로 예산을 효율적으로 운영하고, 어떤 단원에서 학생 질문이 집중되는지 분석해 수업 보완 자료로 활용하려 한다.
  SW와의 관계: 학교 플랫폼과 LearnCraft를 연동하여 학생 계정을 관리하며, API 비용을 집행하는 주체로서 서비스의 지속 도입 여부를 결정하는 핵심 이해관계자이다.

▸ 교과 교사 (이해관계자, 국·영·수 담당 교사)
  현재 불편함: 학생들이 교육과정 범위를 벗어난 AI 답변에 혼란을 겪거나 잘못된 개념을 학습하는 경우를 자주 목격하며, AI 활용 학습의 교육적 품질을 신뢰하기 어려운 상황이다.
  SW 사용 목적: 단원별 시스템 프롬프트의 교육과정 정합성을 최종 검수하여 서비스의 학습 품질을 보장하는 역할을 한다. 단원별 질문 빈도 데이터를 통해 학생들이 어려워하는 개념을 파악하고 수업 방향을 개선하는 데 활용하고자 한다.
  SW와의 관계: LearnCraft의 직접 사용자는 아니지만 시스템 프롬프트 검수와 학습 데이터 활용을 통해 서비스 품질과 교육 효과에 직접적인 영향을 미치는 전문가이다.

▸ 서비스 개발자 (운영자, 컴퓨터공학 박사, 프로그래머)
  현재 불편함: 교육과정별 시스템 프롬프트를 수작업으로 모두 작성하기에는 국·영·수 3개 과목 × 3개 학년 × 다수 단원의 분량이 방대하며, DB 저장 비용과 API 토큰 비용을 효율적으로 관리해야 하는 기술적 부담이 있다.
  SW 사용 목적: 바이브코딩으로 AI가 초안을 생성한 프롬프트를 검토·확정하고, Next.js·Neon DB·Vercel 스택으로 SSO 연동, API 사용량 집계, 관리자 대시보드, 단원별 캐싱 콘텐츠를 구현하고자 한다.
  SW와의 관계: LearnCraft의 설계자이자 구현 주체로서, 서비스의 기술 아키텍처와 프롬프트 품질을 최종 책임지며 지속적으로 기능을 고도화하는 역할을 담당한다.

═══ 기능 설계 ═══
[ 기능 1: 학교 플랫폼 SSO 자동 로그인 ]
기능 설명: 학교 기존 플랫폼과 연동하여 토큰 기반 자동 로그인을 지원합니다. 학생은 별도 가입 없이 학교 계정으로 접속하며, 학년 정보가 자동 설정되고 선행학습을 위한 학년 변경도 가능합니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 학교 플랫폼에서 LearnCraft 접속 버튼을 클릭해요. 별도 가입 없이 학교 계정으로 바로 연결을 시도해요.
    입력 데이터: 학교 플랫폼 로그인 클릭 이벤트
  단계 2 (시스템 처리) — 학교 플랫폼이 발급한 인증 토큰을 LearnCraft 서버가 받아서, 이 학생이 누구인지 확인해요.
    입력 데이터: 학교 플랫폼 발급 SSO 토큰
    출력/결과: 학생 ID, 이름, 학년 정보
  단계 3 (데이터 조회) — 토큰에서 확인된 학생 정보를 LearnCraft DB에서 찾아요. 처음 접속한 학생이라면 새 계정을 자동으로 만들어요.
    입력 데이터: 학생 ID
    출력/결과: 학생 계정 정보 (학년, 과목 설정값)
  단계 4 (조건 분기) — 학생의 현재 학년 설정값이 있는지 확인해요. 처음 접속이라면 학교 플랫폼에서 받은 학년을 기본값으로 저장하고, 기존 이용자라면 마지막으로 저장된 학년 설정을 불러와요.
    입력 데이터: 기존 학년 설정 여부
    출력/결과: 적용할 학년값 (기본 학년 또는 저장된 변경 학년)
  단계 5 (결과 출력) — 로그인이 완료되고 학생의 메인 화면이 열려요. 현재 설정된 학년이 상단에 표시되고, 선행학습을 원하면 학년을 변경할 수 있는 버튼도 함께 보여요.
    출력/결과: 학생 이름, 현재 학년 표시, 학년 변경 버튼

[ 기능 2: 교육과정 단원 기반 AI 학습 채팅 ]
기능 설명: 학년·과목·단원을 선택하면 해당 교육과정 범위에 최적화된 프롬프트로 AI가 답변합니다. 스스로 생각하도록 유도하는 소크라테스식 방식을 기본으로 하며, '더 쉽게', '더 자세히', '답 보기', '관련 퀴즈' 버튼으로 수준별 학습을 지원합니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 학년, 과목(국·영·수), 단원을 단계적으로 선택해요. 기본값은 본인 학년으로 설정되어 있지만, 선행학습을 위해 다른 학년으로 바꿀 수도 있어요.
    입력 데이터: 학년(예: 1학년), 과목(예: 수학), 단원(예: 공통수학1 - 다항식)
    출력/결과: 선택된 학년·과목·단원 정보
  단계 2 (데이터 조회) — 선택한 단원에 해당하는 핵심 공식·개념 요약 자료를 미리 저장된 DB에서 불러와요. AI가 한 번 만들어 캐싱해둔 자료라 빠르게 보여줄 수 있어요.
    입력 데이터: 단원 ID(예: math_common1_polynomial)
    출력/결과: 단원별 핵심 공식·개념 요약 카드
  단계 3 (사용자 입력) — 학생이 해당 단원에 대해 궁금한 내용을 채팅창에 입력해요. 단원 범위 내에서 자유롭게 질문할 수 있어요.
    입력 데이터: 학생 질문(예: 다항식의 나눗셈을 어떻게 해요?)
  단계 4 (시스템 처리) — 학교가 구매한 AI API에 교육과정 맞춤 프롬프트를 붙여서 질문을 보내요. AI는 학생이 스스로 생각할 수 있도록 힌트를 주는 방식으로 답변을 만들어요. 단원 범위를 벗어난 질문이면 해당 범위가 아니라고 안내해요.
    입력 데이터: 학생 질문 + 단원 기반 시스템 프롬프트
    출력/결과: 소크라테스식 AI 답변 또는 범위 이탈 안내 메시지
  단계 5 (결과 출력) — AI 답변이 화면에 표시되고, 답변 아래에 '더 쉽게', '더 자세히', '답 보기', '관련 퀴즈' 버튼이 나타나요. 학생이 버튼을 누르면 원하는 수준에 맞게 추가 설명을 바로 받을 수 있어요.
    출력/결과: AI 답변 텍스트 + 수준별 학습 버튼(더 쉽게 / 더 자세히 / 답 보기 / 관련 퀴즈)

[ 기능 3: 단원별 핵심 개념 자료 제공 ]
기능 설명: 각 단원의 핵심 공식과 개념 요약 자료를 AI가 사전 생성하여 DB에 캐싱해 제공합니다. 학생은 질문 전 기본 개념을 먼저 확인할 수 있으며, 반복 생성 없이 토큰 비용을 절감할 수 있습니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 공부할 학년, 과목, 단원을 선택해요. 예를 들어 '1학년 → 수학 → 공통수학1 → 다항식'처럼 단계적으로 고를 수 있어요.
    입력 데이터: 학년, 과목, 단원 선택 정보
  단계 2 (데이터 조회) — 앱이 DB에서 해당 단원(예: 다항식)에 대해 이미 만들어둔 핵심 공식과 개념 요약 자료가 있는지 확인해요.
    입력 데이터: 선택한 단원 ID
    출력/결과: 캐싱된 단원 자료 존재 여부
  단계 3 (조건 분기) — 자료가 이미 DB에 저장되어 있으면 바로 꺼내서 보여주고, 아직 없으면 AI에게 한 번만 자료를 만들어달라고 요청한 뒤 DB에 저장해요.
    입력 데이터: 자료 존재 여부 (있음 / 없음)
    출력/결과: 기존 자료 반환 또는 AI 생성 후 저장 완료
  단계 4 (결과 출력) — 학생 화면에 해당 단원의 핵심 공식, 개념 요약, 예시 등이 보기 좋게 정리되어 나타나요. 학생은 이 자료를 먼저 읽고 AI에게 질문을 시작할 수 있어요.
    출력/결과: 단원 핵심 개념 자료 화면 (공식, 요약, 예시 포함)

[ 기능 4: 북마크 기반 오답 노트 ]
기능 설명: 학생이 AI 답변 중 중요하다고 생각한 내용을 선택적으로 북마크하여 오답 노트로 저장합니다. 전체 대화를 저장하지 않고 선택 항목만 저장하여 DB 부담을 최소화하며, 본인만 열람 가능한 개인 학습 공간으로 운영됩니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 AI 답변을 읽다가 중요하다고 생각한 내용 옆에 있는 북마크 버튼을 눌러요.
    입력 데이터: 북마크 버튼 클릭, 해당 답변 ID, 학생 ID
  단계 2 (조건 분기) — 이미 북마크한 내용인지 확인해요. 처음 저장하는 거라면 저장을 진행하고, 이미 저장된 내용이라면 북마크를 취소할지 물어봐요.
    입력 데이터: 학생 ID + 답변 ID
    출력/결과: 신규 저장 또는 북마크 취소 안내
  단계 3 (시스템 처리) — 전체 대화 내용은 저장하지 않고, 학생이 북마크한 답변 내용과 해당 과목·단원 정보만 골라서 저장 준비를 해요.
    입력 데이터: 답변 텍스트, 과목명, 단원명, 저장 시각
  단계 4 (데이터 조회) — 학생이 오답 노트 페이지에 들어오면, 본인이 북마크해둔 항목들만 DB에서 불러와요. 다른 사람은 볼 수 없어요.
    입력 데이터: 학생 ID
    출력/결과: 북마크 목록 (과목·단원별로 정리된 저장 답변들)
  단계 5 (결과 출력) — 저장된 북마크 항목들을 과목과 단원별로 묶어서 화면에 보여줘요. 학생은 나중에 시험 전에 이 페이지만 열어봐도 중요한 내용을 복습할 수 있어요.
    출력/결과: 과목·단원별로 정리된 나만의 오답 노트 화면

[ 기능 5: 학생별 일일 사용량 제한 ]
기능 설명: 학교가 API 비용을 부담하는 구조에 맞게 학생별 일일 질문 횟수 제한을 설정합니다. 소수 학생의 과도한 사용을 방지하고 전체 학생이 균등하게 서비스를 이용할 수 있도록 합니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학생이 선택한 학년, 과목, 단원 화면에서 AI에게 질문을 입력해요. 예를 들어 '다항식의 나눗셈을 모르겠어요'처럼 궁금한 내용을 채팅창에 써서 보내요.
    입력 데이터: 학생 ID, 현재 학년·과목·단원 설정, 질문 텍스트
  단계 2 (데이터 조회) — 서버가 DB에서 이 학생이 오늘 질문을 몇 번 했는지 확인해요. 학교에서 정해둔 하루 최대 질문 횟수와 비교해요.
    입력 데이터: 학생 ID, 오늘 날짜
    출력/결과: 오늘 사용 횟수, 일일 제한 횟수
  단계 3 (조건 분기) — 오늘 질문 횟수가 제한 횟수보다 적으면 AI 답변 단계로 넘어가고, 이미 한도를 다 썼으면 더 이상 질문을 받지 않고 안내 메시지를 보여줘요.
    입력 데이터: 현재 사용 횟수, 일일 제한 횟수
  단계 4 (오류 처리) — 오늘 질문 횟수를 모두 소진한 경우, 학생 화면에 '오늘의 질문 횟수를 모두 사용했어요. 내일 다시 이용해 주세요!'라는 안내 메시지를 보여줘요.
    출력/결과: 일일 한도 초과 안내 메시지, 잔여 횟수 0 표시
  단계 5 (시스템 처리) — 질문 횟수가 남아 있으면 DB에 이 학생의 오늘 사용 횟수를 1 늘려서 기록하고, 관리자 대시보드에서 사용 현황을 확인할 수 있도록 저장해요.
    입력 데이터: 학생 ID, 질문 시각, 과목·단원 정보
    출력/결과: 업데이트된 사용 횟수, 누적 API 호출 기록

[ 기능 6: 관리자 사용 현황 대시보드 ]
기능 설명: 학교 관리자가 학생별 사용량, 과목·단원별 질문 빈도, API 비용 현황을 한눈에 확인할 수 있는 대시보드를 제공합니다. 질문이 집중되는 단원을 파악하여 수업 보완 자료로 활용할 수 있습니다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 학교 관리자가 대시보드에 접속하여 조회 기간(오늘, 이번 주, 이번 달 등)과 학년·과목 필터를 선택해요.
    입력 데이터: 조회 기간 선택, 학년/과목 필터 조건
  단계 2 (데이터 조회) — 선택한 조건에 맞게 DB에서 학생별 질문 횟수, 단원별 질문 빈도, API 호출 횟수와 비용 데이터를 가져와요.
    입력 데이터: 조회 기간, 학년, 과목 필터
    출력/결과: 학생별 사용량 목록, 단원별 질문 빈도 수치, 누적 API 비용
  단계 3 (시스템 처리) — 가져온 데이터를 분석해서 질문이 가장 많이 몰린 단원 순위, 사용량 상위 학생 목록, API 비용 합산 결과를 계산해요.
    입력 데이터: 학생별·단원별 원시 데이터
    출력/결과: 단원별 질문 빈도 순위, 학생별 사용량 집계, 총 API 비용
  단계 4 (결과 출력) — 계산된 결과를 학생별 사용량 표, 단원별 질문 빈도 차트, API 비용 현황 카드로 대시보드 화면에 보여줘요. 관리자는 어떤 단원에서 학생들이 가장 어려워하는지 한눈에 확인할 수 있어요.
    출력/결과: 학생별 사용량 표, 단원별 질문 빈도 막대 차트, API 비용 현황 카드

기획서 내용 (아래 형식으로 작성):

[배경 및 필요성]
고등학생들은 학습 과정에서 ChatGPT, Gemini, Claude 등의 AI 서비스를 자발적으로 활용하고 있으나, 여러 문제점이 존재한다. 첫째, 유료와 무료 사용자 간 AI 품질 격차로 인해 교육 불평등이 발생한다. 둘째, 일반 AI는 교육과정 범위를 고려하지 않아 시험과 무관한 내용이나 수준에 맞지 않는 답변을 제공한다. 셋째, 학생들이 AI를 효과적인 학습 도구로 활용하는 방법을 모르고, 단순히 답을 얻는 도구로만 사용하는 경향이 있다. LearnCraft는 이러한 문제를 해결하기 위해 학교가 API 비용을 부담하여 모든 학생에게 균등한 고품질 AI 학습 환경을 제공하고, 고등학교 교육과정에 최적화된 프롬프트 엔지니어링을 통해 학습 효과를 극대화하는 교육과정 기반 AI 학습 플랫폼이다.

[해결 방안]
1. 교육과정 기반 프롬프트 엔지니어링: 고등학교 1·2·3학년 국어·영어·수학 9개 과목-학년 조합에 대해 단원별로 교육과정 범위를 제한하는 시스템 프롬프트를 설계한다. AI가 초안을 생성하고 개발자가 검토하여 품질을 확보하며, 교과 전문 교사의 최종 검수를 통해 신뢰도를 높인다.
2. 학교 플랫폼 SSO 연동: 학교 기존 플랫폼과 토큰 기반 SSO(Single Sign-On) 방식으로 연동하여 학생이 별도 가입 없이 자동 로그인할 수 있도록 한다. 기본적으로 본인 학년이 세팅되며, 선행학습 학생을 위해 학년 변경도 허용한다.
3. 학교 API 공동 구매: 학교가 AI API 비용을 부담함으로써 유료·무료 사용자 간 격차를 해소하고, 모든 학생이 동등하게 고품질 AI 서비스를 이용할 수 있도록 한다.
4. 단원별 콘텐츠 캐싱: 각 단원의 핵심 공식과 개념 요약 자료를 AI가 사전 생성하여 DB에 저장해두고, 학생이 접속 시 캐싱된 자료를 즉시 제공함으로써 API 토큰 비용을 절감하고 학습 진입 장벽을 낮춘다.

[주요 기능]
1. SSO 자동 로그인 및 학년·과목·단원 선택: 학교 플랫폼 토큰으로 자동 로그인되며, 학년(기본값: 본인 학년, 변경 가능) → 과목(국어·영어·수학) → 단원 순으로 단계적으로 선택하여 학습 범위를 설정한다.
2. 교육과정 제한 AI 대화: 선택한 단원 범위 내의 질문에만 답변하며, 범위를 벗어난 질문은 해당 범위가 아님을 안내한다. 단순 답 제공이 아닌 소크라테스식 유도 방식으로 학생 스스로 생각하도록 유도하며, 원할 경우 답을 확인할 수 있다.
3. 수준별 답변 조절 버튼: 답변 이후 '더 쉽게 설명해줘', '더 자세히 설명해줘', '답 보여줘', '관련 개념 퀴즈' 버튼을 제공하여 학생이 자신의 수준에 맞게 능동적으로 학습 깊이를 조절할 수 있도록 한다.
4. 단원별 핵심 개념 자료 제공: 각 단원 진입 시 사전 캐싱된 핵심 공식, 개념 요약 자료를 먼저 제공하여 AI 대화 전 기본 개념을 확인할 수 있도록 한다.
5. 북마크 기반 오답 노트: 전체 대화를 저장하는 대신 학생이 중요하다고 판단한 답변만 선택적으로 북마크하여 저장한다. 저장된 내용은 학생 본인만 열람 가능하며 교사에게는 공개되지 않는다.
6. 일일 사용량 제한: 학교 API 예산 관리를 위해 학생별 일일 질문 횟수 제한을 설정하여 소수 학생의 과도한 사용을 방지한다.
7. 관리자 사용 현황 대시보드: 학교 관리자가 학생별 사용량, 과목별·단원별 질문 빈도, API 비용 현황을 모니터링할 수 있는 대시보드를 제공한다. 단원별 질문 집중도 분석을 통해 수업 보완 자료로도 활용 가능하다.

[기대 효과]
1. 교육 형평성 제고: 학교가 API 비용을 부담함으로써 가정 경제 수준과 무관하게 모든 학생이 동등한 품질의 AI 학습 도구를 사용할 수 있다.
2. 학습 효과 향상: 교육과정 범위로 제한된 답변과 소크라테스식 유도 방식, 수준별 답변 조절 기능을 통해 일반 상용 AI보다 시험에 직결되는 심층적인 학습이 가능하다.
3. AI 리터러시 향상: 학생들이 AI를 단순 답 검색 도구가 아닌 능동적 학습 파트너로 활용하는 경험을 쌓아 AI 활용 역량을 자연스럽게 습득한다.
4. 학교 차원의 데이터 기반 교육 개선: 관리자 대시보드의 단원별 질문 빈도 데이터를 통해 학생들이 어려워하는 단원을 파악하고 수업 자료 보강 등 교육과정 개선에 활용할 수 있다.
5. 비용 효율적 운영: 단원별 콘텐츠 캐싱, 북마크 기반 선택적 저장, 일일 사용량 제한을 통해 API 토큰 비용과 DB 용량을 효율적으로 관리할 수 있다.
