# LearnCraft 국어 교육과정 기준안

작성 기준일: 2026-08-27  
대표 학교: 서대전여자고등학교  
대상: 고등학교 국어 AI 튜터의 과목·단원 데이터와 단원별 프롬프트 설계

## 1. 결론

국어는 학년별로 `국어`라는 단일 항목만 두거나, 과목마다 `교과서 통합 학습` 하나만 두어서는 실제 수업 진도와 작품·활동 범위를 표현할 수 없다. LearnCraft의 국어 과정은 최소한 다음 단계로 구성해야 한다.

`교육과정 개정 연도 → 과목 → 대단원 → 소단원 → 작품·개념·활동`

학생이 AI 튜터를 시작할 때 선택하는 최소 단위는 **작품, 개념 또는 수행 활동**으로 한다. 예를 들어 `1학년 국어 > 공통국어 1 > 빛나는 언어생활 > 음운의 변동` 또는 `2학년 국어 > 문학 > 역사와 함께 흐르는, 문학 > 조선 시대 문학 > 사미인곡`까지 선택되어야 AI가 현재 범위에 맞는 설명과 문제를 제공할 수 있다.

2026학년도 서대전여고 채택본을 기준으로 우선 탑재할 국어 과목은 다음 5개다.

1. 공통국어 1
2. 공통국어 2
3. 문학
4. 화법과 언어
5. 주제 탐구 독서

교과서의 **목차와 채택 출판사**는 범위 식별에 사용하되, 교과서 본문 전체가 제공된 것으로 간주하지 않는다. 학생이 작품이나 지문 사진을 제공하지 않은 상태에서는 실제 문구·문제·교사 설명을 만들어 인용하지 않는다.

## 2. 서대전여고 적용 범위

서대전여고의 2026학년도 검·인정 교과서 선정 결과에서 확인한 국어 채택본은 다음과 같다.

| 학년 | 과목 | 학교 채택 출판사 | 대표 저자 | LearnCraft 처리 |
|---|---|---|---|---|
| 1학년 | 공통국어 1, 공통국어 2 | 비상교육 | 강호영 | 비상교육 목차를 학교 기본값으로 사용 |
| 2학년 | 문학 | 비상교육 | 강호영 | 비상교육 목차와 작품 목록을 학교 기본값으로 사용 |
| 2학년 | 화법과 언어 | 창비교육 | 최형용 | 창비교육 교과서 차례를 학교 기본값으로 사용 |
| 2학년 | 주제 탐구 독서 | 해냄에듀 | 송승훈 | 해냄에듀 교과서 차례를 학교 기본값으로 사용 |
| 3학년 | 기존 2015 개정 과목 | 세부 채택본 미확인 | 미확인 | 현재 운영 범위에서 제외 |

3학년은 선정 결과 문서에 구체적인 신규 채택 정보가 없어 출판사와 목차를 추정하지 않는다. 플랫폼에는 1·2학년만 노출하며, 추후 실제 채택본을 확인한 뒤 별도 교육과정 버전으로 추가한다.

## 4. 앱에 넣을 데이터 구조

국어는 동일 작품이 갈래·시대·주제 수업에서 다르게 사용될 수 있으므로 과목 목차와 학습 콘텐츠를 분리하는 구조가 적합하다.

```ts
type KoreanCourse = {
  id: string;
  code: string;
  title: string;
  curriculumYear: 2022;
  publisher: "VISANG" | "CHANGBI" | "HAENAM";
  recommendedGrades: number[];
};

type KoreanChapter = {
  id: string;
  courseId: string;
  title: string;
  order: number;
};

type KoreanSection = {
  id: string;
  chapterId: string;
  title: string;
  order: number;
};

type KoreanTopic = {
  id: string;
  sectionId: string;
  title: string;
  kind: "TEXT" | "CONCEPT" | "ACTIVITY" | "PROJECT";
  order: number;
  learningGoals: string[];
  evidenceRules: string[];
  keyConcepts: string[];
  commonMistakes: string[];
  scopeExcluded: string[];
  assessmentTags: string[];
  tutorInstructions: string;
};
```

사용자 흐름은 다음과 같이 구성한다.

`학년 선택 → 국어 선택 → 수강 과목 선택 → 대단원 선택 → 소단원/작품·활동 선택 → 튜터 시작`

작품 두 편을 비교하는 소단원은 `section` 아래에 작품별 `topic`을 두되, 비교 감상 요청에서는 같은 `section`의 작품을 함께 참조할 수 있게 한다.

## 5. 단원별 프롬프트 원칙

모든 `KoreanTopic`에는 다음 정보를 저장하고 공통 국어 튜터 프롬프트와 합성한다.

- 현재 작품·개념·활동에서 도달해야 할 학습 목표
- 판단 근거로 사용할 수 있는 본문·자료의 범위
- 화자, 서술자, 글쓴이, 등장인물을 구분하는 기준
- 갈래, 맥락, 표현 방법, 담화 상황 등 핵심 개념
- 학생이 자주 하는 근거 없는 확대 해석과 개념 혼동
- 작품 원문이 없을 때 인용하거나 단정하면 안 되는 내용
- 선택지 판단, 서술형 작성, 비교 감상에 맞는 답변 형식
- 학생 답안을 결론 → 근거 → 개념 → 설명 순으로 고치는 규칙

예를 들어 `음운의 변동`은 다음 제약을 포함한다.

```text
목표: 실제 발음 자료에서 음운 변동을 찾고 변동 전후를 설명한다.
선수 확인: 음운과 음절, 자음·모음, 표기와 발음의 차이를 확인한다.
핵심 연결: 교체·탈락·첨가·축약을 결과만 외우지 않고 발음 환경과 연결한다.
오개념 교정: 맞춤법 표기와 실제 발음을 같은 것으로 처리하지 않는다.
범위 제한: 학교 수업에서 제시되지 않은 예외를 일반 규칙처럼 확대하지 않는다.
풀이 형식: 표기 → 실제 발음 → 변동 환경 → 변동 유형 순서로 설명한다.
```

문학 작품 단원에서는 작품 원문이 제공되지 않았을 때 특정 시구나 문장을 만들어 인용하지 않는다. 작품에 관한 안정적인 갈래·시대 지식은 배경 설명으로 사용할 수 있지만, 정답 근거는 학생이 제공한 지문이나 확인된 자료에 한정한다.

## 6. 영역별 교수 설계

### 6.1 읽기와 매체

- 중심 내용 → 글의 구조 → 주장과 근거 → 관점과 신뢰성 순으로 분석한다.
- 매체 자료는 제작 주체, 목적, 대상 독자, 표현 방식, 누락된 정보를 확인한다.
- 복합양식 자료는 글·사진·도표가 각각 제공하는 정보와 결합 효과를 구분한다.
- 선택지 문제는 맞는 근거뿐 아니라 틀린 선택지를 배제하는 기준도 설명한다.

### 6.2 문학

- 작품 속 표현 → 화자·서술자와 상황 → 정서·태도 → 주제 → 표현 효과 순으로 근거를 찾는다.
- 작품 내부 근거와 사회·문화적 배경지식을 구분한다.
- 가능한 해석이 여러 개라면 각각의 근거와 한계를 함께 제시한다.
- 갈래 이름이나 표현법만 찾고 끝내지 않고 그것이 독자의 이해와 정서에 주는 효과까지 연결한다.

### 6.3 문법과 국어 생활

- 용어 정의 → 언어 자료 관찰 → 규칙 발견 → 새 사례 적용 → 예외 확인 순으로 지도한다.
- 표기, 발음, 형태, 통사, 의미, 담화 층위를 섞지 않는다.
- 규범 문제는 허용 범위와 조건을 확인하고 예외를 일반화하지 않는다.
- 실제 문장을 분석할 때 문장 성분과 품사를 같은 개념으로 처리하지 않는다.

### 6.4 화법

- 목적·참여자·상황 → 사용 전략 → 실제 효과 순으로 분석한다.
- 토의, 토론, 협상, 발표, 연설의 목적과 참여 방식 차이를 명확히 한다.
- 설득 전략은 이성적·감성적·인성적 설득의 이름만 찾지 않고 자료에서 작동하는 방식을 설명한다.
- 의사소통 윤리와 언어의 공공성을 표현의 자유와 함께 검토한다.

### 6.5 쓰기와 탐구 독서

- 쓰기 목적과 예상 독자를 먼저 정하고 내용 생성 → 조직 → 표현 → 고쳐쓰기 순서를 지킨다.
- 탐구는 질문 구체화 → 검색어 설계 → 자료 수집 → 출처 평가 → 관점 비교 → 인용·요약 → 결과 공유로 진행한다.
- 최신 통계나 외부 자료가 필요한 경우 출처를 확인하지 않고 수치·인용·서지 정보를 만들지 않는다.
- 학생 문장을 전부 교체하기보다 의미 전달, 구조, 근거, 표현 정확성 순으로 피드백한다.

## 7. 저작권과 사실성 경계

- 목차에 작품명이 있다는 이유로 교과서 본문 전체를 보유한 것으로 간주하지 않는다.
- 학생이 제공하지 않은 교과서 지문을 길게 재현하거나 복원하지 않는다.
- 짧은 표현을 근거로 다룰 때도 학생 제공 자료 또는 확인 가능한 합법적 자료를 우선한다.
- 교과서 쪽수, 학교 시험 범위, 교사의 해석을 확인 없이 단정하지 않는다.
- 동일 작품이라도 교과서가 발췌한 범위와 학습 활동이 다를 수 있음을 안내한다.
- 생성형 AI가 만든 자료는 원자료와 구분하고, 탐구 보고서에 그대로 인용하지 않게 지도한다.

## 8. 구현 우선순위와 완료 상태

1. 공통국어 1·2의 27개 학습 주제를 학교 채택본 목차로 제공한다.
2. 문학의 작품 31개를 갈래·문학사·삶의 맥락 소단원에 연결한다.
3. 화법과 언어의 문법·화법 14개 주제를 제공한다.
4. 주제 탐구 독서의 탐구 과정 8개를 단계별로 제공한다.
5. 각 주제에 목표·선수 개념·오개념·범위 제한·평가 태그·튜터 지침을 연결한다.
6. 향후 실제 지문과 교사 검수 콘텐츠가 확보되면 `unitContents`의 별도 버전으로 추가한다.

2026-08-27 현재 구현 상태는 다음과 같다.

- 1학년 2과목 27개, 2학년 3과목 53개로 총 5과목 80개 학습 주제를 제공한다.
- 2022 개정과 학교 채택 출판사를 모든 학습 주제에 기록한다.
- 학년 → 국어 → 수강 과목 → 대단원 → 작품·개념·활동 순으로 선택한다.
- 선택한 주제의 경로와 출판사 정보가 AI 시스템 프롬프트에 합성된다.
- 제공되지 않은 본문 인용과 확인되지 않은 시험 범위 추정을 금지한다.
- 3학년은 실제 채택 교과서가 확인될 때까지 공개하지 않는다.
