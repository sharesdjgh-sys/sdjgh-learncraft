# LearnCraft 비상 수학 교육과정 기준안

작성 기준일: 2026-08-26  
대표 학교: 서대전여자고등학교  
대상: 고등학교 수학 AI 튜터의 과목·단원 데이터와 단원별 프롬프트 설계

## 1. 결론

현재처럼 학년별로 수학 단원을 하나만 두면 실제 수업과 시험 범위를 표현할 수 없다. LearnCraft의 수학 과정은 최소한 다음 네 단계로 구성해야 한다.

`교육과정 개정 연도 → 과목 → 대단원 → 중단원/학습 주제`

학생이 AI 튜터를 시작할 때 선택하는 최소 단위는 **중단원 또는 학습 주제**로 한다. 예를 들어 `1학년 수학 > 공통수학 1 > 방정식과 부등식 > 복소수와 이차방정식 > 이차방정식의 판별식`까지 선택되어야 AI가 정확한 범위 안에서 설명하고 문제를 만들 수 있다.

2022 개정 비상교육 교과서 흐름을 기준으로 우선 탑재할 핵심 과목은 다음 7개다.

1. 공통수학 1
2. 공통수학 2
3. 대수
4. 미적분Ⅰ
5. 확률과 통계
6. 미적분Ⅱ
7. 기하

## 2. 서대전여고 적용 범위

서대전여고의 2026학년도 교과서 선정 결과와 전 학년 교육과정 편제표를 함께 확인했다.

| 학년 | 2026학년도 주요 수학 과목 | 학교 채택 출판사 | LearnCraft 처리 |
|---|---|---|---|
| 1학년 | 공통수학 1, 공통수학 2 | 비상교육 | 비상 목차를 학교 기본값으로 사용 |
| 2학년 | 대수, 미적분Ⅰ | 비상교육 | 비상 목차를 학교 기본값으로 사용 |
| 2학년 | 확률과 통계, 기하 | 동아출판 | 국가 교육과정 공통 구조를 우선 사용하고, 학교용 세부 목차는 동아 기준으로 교체 가능하게 설계 |
| 3학년 | 2015 개정 과목과 학교 선택 과목 | 세부 출판사 미확인 | 선정 결과에는 “전년과 동일”만 기재되어 있어 현재 프롬프트 지원 범위에서 제외 |

따라서 플랫폼 전체의 기본 수학 체계는 비상 기준으로 정리하되, 데이터에 `publisher`와 `schoolId`를 두어 학교별 채택 교과서를 덮어쓸 수 있어야 한다. 과목을 학년에 고정하면 다음 해 교육과정 전환이나 학생 선택 과목을 처리하기 어렵기 때문에 `recommendedGrades`와 `schoolOffering`을 분리한다.

## 4. 앱에 넣을 데이터 구조

현재 `LearningUnit` 하나에 과목 설명, 공식, 예시, 추천 질문을 모두 넣는 방식은 단원 수가 늘어날수록 중복이 커진다. 다음처럼 분리하는 것이 좋다.

```ts
type MathCourse = {
  id: string;
  code: string;
  title: string;
  curriculumYear: 2015 | 2022;
  publisher: "VISANG" | "DONGA" | "GENERIC";
  recommendedGrades: number[];
};

type MathChapter = {
  id: string;
  courseId: string;
  title: string;
  order: number;
};

type MathSection = {
  id: string;
  chapterId: string;
  title: string;
  order: number;
};

type MathTopic = {
  id: string;
  sectionId: string;
  title: string;
  order: number;
  conceptGoals: string[];
  prerequisites: string[];
  keyConcepts: string[];
  commonMistakes: string[];
  assessmentTags: string[];
  tutorInstructions: string;
};
```

사용자 흐름은 다음과 같이 구성한다.

`학년 선택 → 현재 수강 과목 선택 → 대단원 선택 → 중단원/학습 주제 선택 → 진단 질문 → 맞춤 튜터 시작`

모바일에서는 네 단계를 한 화면에 모두 펼치지 않고, 하단 시트나 단계별 드릴다운 화면으로 한 단계씩 보여 준다. 최근 학습 단원과 학교 진도를 상단에 바로 노출해 반복 선택을 줄인다.

## 5. 단원별 프롬프트 원칙

단원명만 시스템 프롬프트에 넣어서는 상용 범용 챗봇보다 좋은 수학 답변을 만들기 어렵다. 모든 `MathTopic`에 다음 정보를 저장하고 런타임 시스템 프롬프트에 합성해야 한다.

- 이 단원에서 반드시 도달해야 하는 개념 목표
- 선수 개념과 결손 확인 질문
- 비상 교과서의 용어와 풀이 순서
- 학생이 자주 하는 오개념과 계산 실수
- 허용되는 개념 범위와 아직 사용하면 안 되는 상위 개념
- 기본·표준·도전 난이도의 문제 생성 규칙
- 정답을 바로 공개하기 전 제공할 힌트 단계
- 식 전개와 근거를 생략하지 않는 해설 규칙
- Markdown과 LaTeX 출력 규칙

예를 들어 `이차방정식의 판별식`의 단원 프롬프트는 단순히 “판별식을 설명하라”가 아니라 다음 제약을 포함해야 한다.

```text
목표: 판별식 D=b^2-4ac와 실근의 개수 관계를 설명하고 적용한다.
선수 확인: 이차방정식의 표준형, 근의 공식, 제곱근의 실수 조건을 확인한다.
핵심 연결: 근의 공식에서 루트 내부의 부호가 실근의 개수를 결정함을 유도한다.
오개념 교정: D=0일 때 '근이 없다'가 아니라 서로 같은 두 실근, 즉 중근임을 강조한다.
범위 제한: 복소수 해의 계산이 질문의 핵심이 아니라면 불필요하게 확장하지 않는다.
풀이 형식: 식을 LaTeX로 쓰고, D 계산 → 부호 판단 → 결론의 순서를 지킨다.
```

따라서 단원 프롬프트는 하나의 거대한 문자열 파일로 만들기보다, 구조화된 단원 데이터와 공통 수학 튜터 시스템 프롬프트를 결합하는 방식으로 구현한다.

## 6. 구현 우선순위

1. 서대전여고 1학년 필수인 공통수학 1·2의 36개 학습 주제를 먼저 탑재한다.
2. 서대전여고 2학년 비상 채택 과목인 대수와 미적분Ⅰ을 탑재한다.
3. 확률과 통계와 기하는 학교 채택본이 동아출판임을 UI에 정확히 표시하고, 범용 국가 교육과정 단원으로 제공한다.
4. 미적분Ⅱ와 2015 개정 3학년 과목을 별도 버전으로 추가한다.
5. 각 학습 주제에 목표·선수 개념·오개념·평가 태그·단원 프롬프트를 연결한다.
6. 학교 진도와 학생의 최근 학습 이력을 이용해 기본 선택 단원을 자동 제안한다.

## 7. 구현 완료 상태 (2026-08-26)

- 비상교육 2022 개정 수학 7과목을 93개 학습 주제로 구조화했다.
- 2026-08-27 현재 튜터 공개 범위는 교과서가 확인된 1·2학년으로 제한했다. 미적분Ⅱ를 제외한 수학 6과목 76개 주제와 채택 출판사 목차를 반영한 국어·영어 9개 과정 186개 주제, 총 15과정 262개 주제를 제공한다.
- 1·2학년 × 국어·영어·수학의 여섯 조합에 학년·과목 전용 시스템 프롬프트를 적용하고, 3학년 요청은 공개하지 않는다.
- 공통수학 1·2, 대수, 미적분Ⅰ에는 서대전여고 채택 과목 표시를 적용했다.
- 확률과 통계와 기하는 서대전여고 실제 채택본이 동아출판임을 선택 화면에 안내한다.
- 각 주제에 학습 목표, 핵심 개념, 선수 개념, 자주 하는 실수, 범위 제한, 평가 태그, 공식, 예시 및 전용 튜터 지침을 연결했다.
- 학년 → 과목 → 과정 → 대단원/중단원/학습 주제 순으로 선택하는 반응형 UI를 구현했다.
- 선택한 주제 데이터가 Gemini 시스템 프롬프트에 합성되며 Markdown 및 LaTeX 형식으로 스트리밍된다.
- 현재 시드 정의는 학교 1개, 테스트 사용자 2명, 과정 15개, 전체 학습 주제 262개다.
