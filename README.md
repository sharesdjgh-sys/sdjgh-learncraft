# LearnCraft

LearnCraft는 고등학교 교육과정과 학교 채택 교과서를 기반으로 학생에게 수준별 맞춤 학습을 제공하는 AI 튜터 서비스입니다. 학생은 과목과 단원을 선택해 개념 설명, 예시, 추천 질문 등으로 학습할 수 있으며, 관리자는 교육과정과 교과서 자료, 학생 계정 및 서비스 사용 현황을 관리할 수 있습니다.
