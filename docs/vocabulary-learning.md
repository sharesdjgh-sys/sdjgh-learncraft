# 대화창 안에서 교과 어휘 배우기

목차 위 출판사·교육과정 안내 대신 ‘교과 핵심 어휘’ 버튼을 표시한다. 버튼을 누르면 기존 /learn 오른쪽 학습 창에 어휘 영역이 열린다. 선택한 대단원 아래에 소단원을 교육과정 순서대로 배치하고 각 소단원의 keywords를 함께 묶어, 학생이 배울 흐름을 따라가며 단어를 고를 수 있게 한다. 어휘 영역에서 대단원을 바꾸면 소단원과 단어 목록도 함께 바뀐다. 별도 어휘 페이지나 별도 어휘 대화 저장소는 사용하지 않는다.

주요 단어를 누르면 /api/vocabulary에서 무료 기본 설명을 가져와 기존 단원 대화에 사용자 질문과 AI 설명으로 추가한다. 기존 본문과 대화를 유지하고 동일한 북마크·복사·세션 복원을 사용한다. 생성 실패 시 위의 단어를 다시 누르면 재시도한다.

‘궁금한 단어’ 입력창은 목록에 없는 단어도 허용한다. /api/ai/tutor의 VOCABULARY 모드로 전송하고 현재 대단원 문맥에서 설명한다. 기존 DIRECT QUESTION 사용 횟수와 실패 반환 정책을 적용한다. 추가 질문은 기존 대화 입력창에서 이어갈 수 있다.

어휘 답변 아래 후속 학습은 일반 단원 학습과 구분한다. ‘예문으로 익히기’, ‘비슷한 말과 비교’, ‘기억에 남게 정리’, ‘어휘 확인 문제’를 제공하고 방금 설명한 어휘와 대단원 문맥을 이어서 다룬다. 이 후속 요청은 기존 FOLLOW_UP 정책에 따라 질문 횟수에서 차감하지 않는다.

기본 설명 API는 학교·과목·단원에 등록된 키워드만 무료 생성한다. 공유 캐시는 학교·과목·단원·단어·설명 맥락·프롬프트 버전으로 구분한다. 단원 내용 변경 시 새 캐시를 사용하며 생성 임대 60초와 소유 토큰으로 동시 생성을 막는다. 생성은 45초로 제한하고 실패 결과는 저장하지 않는다. DB 없는 개발 환경에서는 메모리 캐시를 사용한다.

DB를 사용하는 환경에서는 0011_vocabulary_explanations 마이그레이션이 필요하다. 기존 교육과정 전체 재생성은 필요 없다. 학생 질문은 공유 설명 캐시에 저장하지 않는다.

검증: npm run test:vocabulary, 타입 검사, 린트. 단원 전환·주요 단어 선택·같은 대화에서의 질문·목록 밖 단어·무료 설명과 유료 질문·실패 반환·기존 대화 보존을 확인한다.

설명은 고정 소제목 없이 content Markdown 문단으로 생성한다. 어원·비유·일상 장면을 단어에 맞게 선택하며, 프롬프트 버전 2부터 이전 서식의 캐시를 재사용하지 않는다.

학생용 어휘에는 튜터 검색용 키워드나 편집용 목차 문구를 그대로 사용하지 않는다. 1·2학년 국어·영어·수학 정적 과정은 과목별로 검토한 목록을 사용하고, AI 과정 생성 시에는 실제 교과 개념어·전문용어·관용 표현만 keywords에 저장한다. 과목명, 학습 목표, 활동 안내, 정답·해설, 자료 출처 같은 편집용 문구는 저장 전과 화면 표시 전에 제거하며, 공백과 문장부호만 다른 중복어도 하나로 합친다. ‘화학 평형’, ‘반응 속도’처럼 대단원 제목 자체가 중요한 교과 개념인 경우에는 어휘로 유지한다.

기존 공개 교육과정은 `npx tsx scripts/clean-vocabulary-keywords.ts`로 변경 예정 내용을 확인하고, 학교 범위를 지정한 `--apply --school-id <uuid>`로 `units`와 저장된 과정 JSON을 함께 정리한다. 정리 도구는 현재 공개된 교육과정의 활성·공개 과정만 다루며 과정별 갱신 후 다시 검사한다.
