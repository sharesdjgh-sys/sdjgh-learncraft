# 교과 렌더링 검증

`npm run test:rendering`으로 교과별 회귀 검사를 실행합니다. 실제 답변에 사용하는 Markdown과 짧은 질문·라벨용 InlineMarkdown을 모두 검사합니다.

- 국어, 영어, 수학, 물리학, 화학, 생명과학, 지구과학, 지리, 역사, 사회·경제, 윤리, 음악, 미술, 체육, 기술·가정, 정보, 제2외국어, 진로, 기타 교과의 대표 예시 54개
- 굵게, 표, 코드 보존, 달러·괄호 수식 구분자, 행렬, 벡터, 분수, 단위, 화학식·전하·동위원소·반응식
- KaTeX 클래스 존재만 확인하지 않고, 보이는 명령어·빨간 오류 글자·표시 실패도 검사. 접근성 MathML의 원문 annotation은 검사에서 제외
- 잘못된 수식과 그래프 수식 라벨, 지원하지 않는 raw Mermaid 블록은 원문 대신 안내 표시
- 스트리밍 중 미완성 수식·도식은 작성 중 안내, 완료된 잘못된 시각자료는 실패 안내

추가 검사: `npm run test:math`, `npm run test:markdown`, `npm run test:visuals`, `npm run test:figure`, `npm run test:graph`.

2026-09-07 Edge 확인: 대표 예시 48개를 데스크톱 1280px 및 모바일 390px에서 검사했으며 표시 오류와 페이지 가로 넘침이 없었습니다. 관계도, 연표, 지도, 악보, 함수 그래프, 막대그래프도 실제 SVG 생성을 확인했습니다. Mermaid의 엔티티·줄바꿈 회귀 예시는 별도 fixtures/mermaid-label-cases.ts에서 관리합니다.

수식은 공통 LearningMath에서 KaTeX와 내장 mhchem 확장을 함께 사용합니다. 화학 명령 내부는 일반 첨자 크기 보정에서 제외합니다. 시각자료 JSON의 일반 텍스트 필드는 유니코드 기호를 사용하고 복잡한 수식은 본문에 작성하도록 생성 지침을 구분했습니다.

이 검사는 대표 출력 형식의 회귀 검사이며 모든 교육과정 단원이나 생성 가능한 모든 답변을 검수한 것은 아닙니다. 학습 내용·정답의 정확성과 외부 이미지 서비스의 가용성은 별도 검토 대상입니다. 새 피드백이 들어오면 재현 예시를 fixture에 추가합니다.
