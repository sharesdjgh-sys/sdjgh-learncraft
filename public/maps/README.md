# Learning map data

countries-50m.json and countries-10m.json are copied from world-atlas 2.0.2 (Natural Earth, 1:50m and 1:10m).
countries-10m.json is loaded only when a teacher zooms far into the social studies map (/teacher/social-map).
Source: https://github.com/topojson/world-atlas
Natural Earth data: public domain, https://www.naturalearthdata.com/about/terms-of-use/
This is a generalized basemap, not a current or historical boundary authority.
World Atlas copyright and license are in world-atlas-LICENSE.txt.
To update: review the new data and replace the file from the pinned package.
